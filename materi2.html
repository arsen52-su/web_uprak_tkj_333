Manajemen MikroTik dan Routing

1. Mengenal MikroTik dan RouterOS

MikroTik itu perangkat router handal yang di dalamnya jalan sistem operasi bernama RouterOS. Buat ngatur-ngatur konfigurasinya, biasanya kita pakai aplikasi khusus di komputer Windows yang namanya WinBox (lewat GUI biar gampang diklik-klik).

2. Konfigurasi Dasar di MikroTik

Sebelum jaringan bisa jalan normal, ada beberapa langkah awal wajib yang biasa kita setting:

  • IP Address: Mengatur alamat IP di setiap port interface (misal ether1 buat internet dari ISP, ether2 buat jalur lokal ke client).
  • DHCP Client & Server: DHCP Client dipakai supaya router bisa nangkep internet dari sumber luar secara otomatis, sedangkan DHCP Server bikin router otomatis bagi-bagi IP ke komputer client.
  • DNS (Domain Name System): Mengatur peladen DNS (misal pakai 8.8.8.8) supaya komputer client bisa buka google.com pakai nama teks, bukan cuma angka IP doang.

3. NAT (Network Address Translation) & Masquerade

Nah, fitur ini penting banget supaya komputer lokal (yang pakai IP lokal/private) bisa ikut nyambung ke internet publik. Di MikroTik, kita biasanya pakai aturan IP > Firewall > NAT dengan action masquerade.

4. Konsep Routing Jaringan

Routing adalah mekanisme pengiriman paket data dari satu jaringan ke jaringan lain lewat jalur terbaik. Dibagi jadi dua jenis utama:

  • Static Routing: Jalur rutenya kita ketik dan daftarkan secara manual satu-satu oleh administrator jaringan. Cocok buat jaringan skala kecil.
  • Dynamic Routing: Jalur rutenya bisa dicari dan di-update sendiri secara otomatis antar router pakai protokol khusus (contohnya OSPF atau RIP).
