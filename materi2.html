Manajemen MikroTik dan Routing

A. Pengertian MikroTik & Fiturnya[span_26](start_span)[span_26](end_span)

MikroTik adalah perangkat dan sistem operasi jaringan (RouterOS) yang digunakan untuk mengatur dan mengontrol lalu lintas data[span_27](start_span)[span_27](end_span). Untuk mengonfigurasinya secara grafis (GUI), digunakan aplikasi WinBox[span_28](start_span)[span_28](end_span).

Fitur Utama MikroTik: IP Address, DHCP Server/Client, DNS, NAT, Firewall, Hotspot, Bandwidth Management, dan Routing[span_29](start_span)[span_29](end_span).

B. Routing Jaringan[span_30](start_span)[span_30](end_span)

Routing adalah proses menentukan jalur pengiriman paket data dari satu jaringan ke jaringan lainnya[span_31](start_span)[span_31](end_span). Jenis routing dibagi dua:

  • Static Routing: Jalur ditentukan secara manual oleh administrator[span_32](start_span)[span_32](end_span).
  • Dynamic Routing: Jalur diperbarui otomatis oleh protokol routing (seperti OSPF, RIP, BGP)[span_33](start_span)[span_33](end_span).

C. NAT & Manajemen Bandwidth[span_34](start_span)[span_34](end_span)

NAT (Network Address Translation) mengubah IP sumber/tujuan, di mana Masquerade sering digunakan untuk berbagi koneksi internet[span_35](start_span)[span_35](end_span). Adapun Manajemen Bandwidth mengatur kecepatan internet klien menggunakan fitur seperti Simple Queue[span_36](start_span)[span_36](end_span).

D. Dasar Konfigurasi & Pengujian MikroTik[span_37](start_span)[span_37](end_span)

Urutan dasar konfigurasi: Buka WinBox ➔ Atur Identitas Router ➔ IP Address ➔ DHCP Client/WAN ➔ DHCP Server LAN ➔ DNS ➔ NAT ➔ Uji Koneksi[span_38](start_span)[span_38](end_span). Pengujian dilakukan dengan melakukan ping ke gateway/internet serta memeriksa tabel routing[span_39](start_span)[span_39](end_span).
