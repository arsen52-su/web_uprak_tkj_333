Manajemen MikroTik dan Routing

A. Pengertian MikroTik & Fiturnya

MikroTik adalah perangkat dan sistem operasi jaringan (RouterOS) yang digunakan untuk mengatur dan mengontrol lalu lintas data. Untuk mengonfigurasinya secara grafis (GUI), digunakan aplikasi WinBox.

Fitur Utama MikroTik: IP Address, DHCP Server/Client, DNS, NAT, Firewall, Hotspot, Bandwidth Management, dan Routing.

B. Routing Jaringan

Routing adalah proses menentukan jalur pengiriman paket data dari satu jaringan ke jaringan lainnya. Jenis routing dibagi dua:

  • Static Routing: Jalur ditentukan secara manual oleh administrator.
  • Dynamic Routing: Jalur diperbarui otomatis oleh protokol routing (seperti OSPF, RIP, BGP).

C. NAT & Manajemen Bandwidth

NAT (Network Address Translation) mengubah IP sumber/tujuan, di mana Masquerade sering digunakan untuk berbagi koneksi internet. Adapun Manajemen Bandwidth mengatur kecepatan internet klien menggunakan fitur seperti Simple Queue.

D. Dasar Konfigurasi & Pengujian MikroTik

Urutan dasar konfigurasi: Buka WinBox -> Atur Identitas Router -> IP Address -> DHCP Client/WAN -> DHCP Server LAN -> DNS -> NAT -> Uji Koneksi. Pengujian dilakukan dengan melakukan ping ke gateway/internet serta memeriksa tabel routing.
