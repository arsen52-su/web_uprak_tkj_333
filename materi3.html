Administrasi Sistem Jaringan

🖥️ Pengenalan Server

Administrasi sistem jaringan berfokus pada pengelolaan server (biasanya menggunakan OS Linux seperti Debian) untuk melayani berbagai kebutuhan klien dalam jaringan lokal maupun internet.

🛠️ Layanan Server Utama:

  • Web Server (Apache/Nginx): Menyiapkan wadah agar halaman website atau file bisa diakses oleh komputer lain dalam jaringan.
  • DNS Server (BIND9): Menerjemahkan alamat IP server menjadi sebuah nama domain yang mudah diingat (contoh: ujian-tkj.com).
  • Keamanan Server: Mengatur hak akses pengguna (permission) dan firewall dasar pada sistem operasi server Linux.
