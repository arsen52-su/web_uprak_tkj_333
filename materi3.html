Administrasi Sistem Jaringan

A. Administrasi Server Jaringan

Administrasi server adalah proses mengelola, mengonfigurasi, dan memelihara layanan server agar dapat diakses dengan aman dan stabil oleh klien dalam jaringan.

B. Layanan Utama Server

  • DHCP Server: Memberikan alamat IP secara otomatis ke perangkat klien.
  • DNS Server: Menerjemahkan alamat IP menjadi nama domain yang mudah diingat (misal: website.com).
  • Web Server: Menyimpan dan menyajikan halaman website kepada pengguna (Contoh: Apache, Nginx).

C. Keamanan Jaringan & Maintenance

Melakukan backup data secara berkala, memantau lalu lintas jaringan, serta menerapkan hak akses (firewall/user permission) untuk mencegah akses ilegal.
