Administrasi Sistem Jaringan

1. Apa itu Administrasi Server?

Administrasi server adalah tugas seorang administrator jaringan untuk menginstal, mengonfigurasi, mengelola, dan merawat berbagai layanan server supaya bisa diakses oleh client dengan aman, cepat, dan stabil 24/7.

2. Layanan Server Utama yang Sering Dipelajari

  • DHCP Server: Layanan yang otomatis menyebarkan nomor IP Address ke setiap perangkat baru yang nyambung ke jaringan, jadi kita nggak perlu setting IP manual satu-satu di tiap laptop.
  • DNS Server: Berfungsi layaknya buku telepon internet yang menerjemahkan nama domain web (misalnya sekolahku.sch.id) menjadi deretan angka IP Address server tujuan.
  • Web Server: Perangkat lunak server (seperti Apache, Nginx, atau IIS) yang bertugas menyimpan file-file website dan menampilkannya saat ada pengguna yang mengakses lewat browser.
  • FTP Server (File Transfer Protocol): Layanan khusus buat kirim-kirim atau upload/download file data antar komputer client dan server dengan gampang.

3. Keamanan Jaringan & Maintenance (Pemeliharaan)

Punya jaringan aja belum cukup kalau nggak aman. Makanya ada beberapa hal penting yang harus diurus:

  • Firewall & Filtering: Menyaring lalu lintas data yang keluar masuk, memblokir situs atau port berbahaya, serta mencegah serangan hacker.
  • Manajemen User & Hak Akses: Membatasi siapa saja yang boleh buka folder penting atau merubah sistem (mencegah sabotase internal).
  • Backup Berkala: Rutin mencadangkan data penting ke tempat lain supaya kalau server tiba-tiba rusak atau jebol, data sekolah/kantor aman dan bisa dipulihkan dengan cepat.
